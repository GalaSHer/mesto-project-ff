# Проектная работа Mesto
https://github.com/GalaSHer/mesto-project-ff.git

Проект представляет небольшую социальную сеть, где отображаются фотографии по ссылкам пользователей. 

## Функциональность проекта: 
* Профиль пользователя: пользователи могут заполнять и редактировать свои профили, добавляя/изменяя информацию о себе, такую как имя, фотография, сфера деятельности;
* Посты: пользователи могут публиковать фотографии и удалять их, а также ставить "лайки" на публикации других пользователей и убирать их.

## Стек технологий:
* HTML
* CSS
* JavaScript
* сборка проекта с помощью Webpack
* babel
* postCSS
* Git
* API

## Инструкция по использованию проекта
1. клонируйте репозиторий
2. в командной строке перейдите в папку репозитория mesto_project_ff/
3. выполните команду npm install
4. выполните команду npm run dev
